快速开始

macOS 安装

  1. 下载 DMG 文件
  2. 打开 DMG，将 VMStart.app 拖入应用程序文件夹
  3. 安装 QEMU: brew install qemu
  4. 启动 VMStart

Windows 安装

  1. 下载对应架构的 EXE 文件 (x86_64 或 ARM64)
  2. 运行 VMStart.exe
  3. 按照向导配置虚拟机
