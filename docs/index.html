快速开始

macOS 安装

  1. 下载 PKG 安装包（推荐）
  2. 右键点击 PKG → 打开 → 输入密码安装
  3. 安装完成后自动解除隔离，可直接打开
  4. 如仍提示警告：系统设置 → 隐私与安全性 → 仍要打开

或终端安装：sudo installer -pkg VMStart.pkg -target /

Windows 安装

  1. 下载对应架构的 EXE 文件
  2. 双击运行 VMStart.exe
  3. 如提示 SmartScreen，点击「仍要运行」
  4. 按照向导配置虚拟机

内置 Linux

  1. 打开 VMStart，点击「使用 Linux」
  2. 选择「服务器版」或「图形界面」
  3. 系统自动以推荐配置启动
  4. Server: 2GB RAM / Desktop: 4GB RAM
