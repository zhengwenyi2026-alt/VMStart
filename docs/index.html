快速开始

macOS 安装

  1. 打开“终端”，执行上方的一行安装命令
  2. 安装完成后 VMStart 会自动打开，无需任何安全设置
  3. 也可下载 ZIP 手动安装：解压后把 VMStart.app 拖入“应用程序”，再在终端执行下载区下方的解除命令
  4. 启动 VMStart，开始创建虚拟机

Windows 安装

  1. 下载对应架构的 EXE 文件
  2. 双击运行 VMStart.exe
  3. 如提示 SmartScreen，点击「仍要运行」
  4. 按照向导配置虚拟机

终端操控

不打开界面，也能用 vmstart 命令管理虚拟机和下载镜像（macOS）

启用 vmstart 命令
sudo mkdir -p /usr/local/bin && sudo ln -sf /Applications/VMStart.app/Contents/Resources/CLI/vmstart /usr/local/bin/vmstart
用一行命令安装的已自动启用，可跳过。手动安装 ZIP 的，在终端执行一次即可，之后输入 vmstart 查看全部命令。
$ vmstart list

$ vmstart start ubuntu

虚拟机

vmstart list
列出所有虚拟机
vmstart info <名称>
显示虚拟机配置
vmstart show [名称]
打开 VMStart 并选中虚拟机
vmstart start <名称>
启动虚拟机
vmstart stop <名称>
停止虚拟机
vmstart add <镜像文件>
按最佳配置把本地镜像添加为虚拟机

镜像下载

vmstart download <网址> [--add]
下载镜像，--add 表示完成后自动添加
vmstart watch
在终端实时显示下载进度
vmstart downloads [--json]
查看下载列表
vmstart pause | resume | cancel [序号]
暂停、继续或取消下载
vmstart auto-add on | off
下载完成后是否自动添加
vmstart open <网址>
在镜像工具中打开网页

名称可以是虚拟机全名、名称开头几个字或 ID。输入 vmstart help 查看完整帮助。
